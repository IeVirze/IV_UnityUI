# Game character build screen

Skills gained: 
* Basic knowledge of working with various Unity assets
* Understanding of 3D sprites and how to add them in 2D scene
* Screen connection
* Better debugging
* Skills of working with C#

## The game intro screen descritpiton
3 screens with the following functionality: 
1) Allows input of age and name of the character, allows to exit game, or continue to the next screen and switchin off/on music
2) Allows to modify the character look and choose if it is female or male character as well as height and width
3) Show the hero description depending on the character gender as well as show character name and the year of birth if calculated from 2026
